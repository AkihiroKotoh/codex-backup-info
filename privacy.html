Codex Backup

Privacy policy

Codex Backup is a personal rclone backup configuration run locally. It uses Google authorization and the Google Drive API to copy selected files and inspect existing backups.

Access and use

The configuration requests permission to read, create, change and delete Google Drive files. This permission applies across each authorized Drive account. Backup-folder settings limit the scripts’ operations; they are not a Google-enforced permission restriction.

The backup procedure copies new or changed files, retains cloud files removed locally, and retains replaced versions in a history folder. It does not automatically purge backup history.

Credentials and data

Authorization tokens and app credentials are kept locally with restricted access and excluded from this configuration’s backups and Git. No additional application server is operated to receive the tokens or backup contents.

Backup files are sent to Google Drive. This personal configuration does not sell backup contents, use them for advertising, or send them to other recipients. Google processes data under its applicable terms and privacy policy.

Control and retention

Access can be revoked through Google Account settings. Revocation stops future authorized access but does not delete existing backups. The owner controls backup retention and deletion through Google Drive.

This website

These informational pages contain no backup files or credentials. They use no forms, advertising, analytics scripts or third-party embedded resources. GitHub Pages hosts this website and logs visitor IP addresses for security, as described in GitHub’s documentation and its privacy statement.
